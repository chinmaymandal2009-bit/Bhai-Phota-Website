# শুভ ভাইফোঁটা Website
A mobile-friendly Bengali Bhai Phota greeting website.

## Run
Open `index.html` in a browser. For best results, use a modern browser and an internet connection (the card download feature loads html2canvas from a CDN).

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` to the repository root.
3. Open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch, select `main` and `/ (root)`, then Save.
5. Wait for the published website link to appear.

No Firebase or database is used. Photos are processed locally in the browser.
